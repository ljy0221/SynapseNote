## layout (Structure)
**페이지의 전체적인 "틀"이나 "구조"를 잡는 컴포넌트입니다.**

* **역할:** `children`을 감싸거나, 화면의 고정된 영역(헤더, 사이드바 등)을 배치합니다.
* **특징:** 페이지마다 반복되는 레이아웃 패턴을 정의합니다.
* **Electron 관련:** 윈도우 프레임, 타이틀바, 메뉴 등 앱 껍데기와 관련된 요소가 위치합니다.

| 예시 (Example)         | 설명 |
|:---------------------| :--- |
| `MainLayout.tsx`     | 사이드바와 헤더가 포함된 기본 레이아웃 |
| `AuthLayout.tsx`     | 로그인/회원가입 페이지용 레이아웃 |
| `Sidebar.tsx`        | 네비게이션 사이드바 |
| `TitleBar.tsx`       | (Electron) 커스텀 타이틀바 및 드래그 영역 |
| `WindowControls.tsx` | (Electron) 최소화, 최대화, 닫기 버튼 |
